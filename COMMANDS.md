# Довідник команд CardputerOS

Усі 64 вбудовані команди оболонки, правила синтаксису, клавіші та мова скриптів `.lua`.

Позначення в синтаксисі:

- `[...]` — необов'язкова частина;
- `...` — можна повторити;
- `ВЕЛИКІ` або слова у звичайному записі — значення, які підставляєте самі.

## 1. Оболонка: загальні правила

### Конвеєри і перенаправлення

- `команда1 | команда2` — вивід першої команди стає вводом другої. Ввід читають `cat` (без файлів), `head`, `tail`, `wc`, `grep`, `sort`, `uniq`, `tee`.
- `команда > файл` — записати вивід у файл. Існуючий файл перезаписується.
- `команда >> файл` — дописати вивід у кінець файлу.

### Списки команд

- `команда1 ; команда2` — виконати обидві незалежно від результату.
- `команда1 && команда2` — друга виконується, якщо перша завершилася успішно (код 0).
- `команда1 || команда2` — друга виконується, якщо перша завершилася з помилкою.

### Змінні і код виходу

- `NAME=значення` — присвоїти змінну (у рядку, де немає інших слів).
- `$NAME` або `${NAME}` — значення змінної.
- `$?` — код виходу останньої команди.

Вбудовані змінні: `USER`, `HOME`, `PWD`, `HOSTNAME` (значення `cardputer`), `PATH` (значення `/apps`), `SHELL`, `TERM`.

### Лапки і спецсимволи

- `"текст"` зберігає пробіли, але підставляє `$змінні`.
- `'текст'` зберігає все буквально, без підстановок.
- `\` екранує наступний символ.
- `~` на початку слова означає домашню папку (`$HOME`).

### Шаблони в іменах файлів

- `*` означає будь-яку кількість символів, `?` означає один символ.
- Приклад: `ls *.lua`. Якщо збігів немає, слово передається як є.

### Коди виходу

Успіх дає код 0. Більшість команд повертають 1 при помилці. Якщо команди немає, оболонка повертає 127.

### Що не підтримується

`$(...)`, `<`, фонові задачі `&`, `if`, `for`, `while`, регулярні вирази (`grep` шукає підрядок), процеси (`ps`, `kill`), справжні права доступу, `cd -`.

## 2. Вхід, користувачі і права

| Команда | Синтаксис | Опис |
|---|---|---|
| `su` | `su [користувач]` | Перейти до іншого користувача. Root переходить без пароля, решта вводить пароль цільового користувача. Поточна папка не змінюється. |
| `sudo` | `sudo команда [аргументи...]` | Виконати команду від root. Питає пароль поточного користувача. Для root виконується одразу. Команда передається як рядок, тому дані з попередньої команди конвеєра до неї не доходять. |
| `passwd` | `passwd [користувач]` | Змінити пароль. Root може змінити пароль будь-кому без старого. Звичайний користувач змінює лише свій і спершу вводить старий. Новий пароль вводиться двічі. |
| `useradd` | `useradd ім'я` | Створити користувача. Тільки root. Ім'я: малі латинські літери, цифри, `_` і `-` (не першим), до 16 символів. Створює `/home/ім'я` і питає пароль двічі. |
| `userdel` | `userdel ім'я` | Видалити користувача. Тільки root. Користувача `root` видалити не можна. Папку `/home/ім'я` залишає. |
| `users` | `users` | Показати список користувачів. |
| `login` | `login` | Відкрити вікно входу поверх поточної сесії. |
| `logout` | `logout` | Закрити всі вікна і показати вікно входу. |
| `whoami` | `whoami` | Показати ім'я поточного користувача. |
| `id` | `id` | Показати UID, GID і групу поточного користувача. |

### Права доступу

- **root** має повний доступ.
- **Звичайний користувач** пише лише у свою папку `/home/<ім'я>`. Читає все, крім `/root` і `/etc/passwd`.
- **Тільки root** може виконати `reboot`, `poweroff`, `wifi connect`, `wifi disconnect`, `useradd`, `userdel`, а також змінити пароль іншому користувачу через `passwd`.
- Перенаправлення `>` і `>>` перевіряє права того, хто запускає команду, так само як у Linux.

Після запуску пристрою відкривається вікно входу. Доки ви не ввійшли, інші вікна й гарячі клавіші недоступні.

## 3. Файли і каталоги

| Команда | Синтаксис | Опис |
|---|---|---|
| `ls` | `ls [-al] [каталог...]` | Показати вміст каталогу (без аргументу поточного). `-a` показує приховані, тобто імена з крапки. `-l` додає довгий формат: тип, розмір, ім'я. Права в `-l` умовні. Виводить до 300 записів. |
| `cd` | `cd [каталог]` | Змінити поточну папку. Без аргументу переходить у домашню. Розуміє `..` і `.`. |
| `pwd` | `pwd` | Показати поточну папку. |
| `touch` | `touch файл...` | Створити порожній файл. Існуючий файл не змінює. |
| `mkdir` | `mkdir [-p] каталог...` | Створити каталог. `-p` створює також усі проміжні каталоги. |
| `rm` | `rm [-rf] шлях...` | Видалити файли. `-r` (або `-R`) видаляє каталоги разом із вмістом. `-f` мовчки ігнорує відсутні файли. Корінь `/` не видаляється. |
| `cp` | `cp джерело призначення` | Скопіювати файл. Якщо призначення є каталогом, файл копіюється всередину. Існуючий файл перезаписується. Копіює потоково, розмір не обмежений. |
| `mv` | `mv джерело призначення` | Перемістити або перейменувати файл. Існуючий файл у призначенні перезаписується. |
| `find` | `find [каталог] [-name шаблон]` | Рекурсивний пошук за іменем. Шаблон з `*` і `?`, наприклад `-name "*.lua"`. Глибина до 8 рівнів. |
| `tree` | `tree [каталог]` | Дерево каталогів (глибина до 5) і підсумок: кількість каталогів і файлів. |
| `du` | `du [-h] [шлях]` | Розмір каталогу або файлу. За замовчуванням у кілобайтах. `-h` показує в байтах, КБ або МБ. |
| `df` | `df` | Місце на SD-карті в МБ: розмір, зайнято, вільно, відсоток. |
| `basename` | `basename шлях` | Залишити лише ім'я файлу, без каталогів. |
| `dirname` | `dirname шлях` | Залишити лише каталог, без імені файлу. |
| `files` | `files [каталог]` | Відкрити вікно файлового менеджера. |

## 4. Текст і конвеєри

| Команда | Синтаксис | Опис |
|---|---|---|
| `cat` | `cat [-n] [файл...]` | Вивести файли. `-n` нумерує рядки. Без файлів читає ввід з конвеєра. Читає до 8 КБ на файл. |
| `echo` | `echo [-n] [аргумент...]` | Вивести аргументи через пробіл. `-n` не переводить рядок у кінці. |
| `printf` | `printf формат [аргумент...]` | Форматований вивід. Підтримує `%s` (рядок), `%d` (число), `%%` (знак відсотка), `\n` і `\t`. |
| `grep` | `grep [-inv] шаблон [файл]` | Показати рядки, що містять шаблон. Це пошук підрядка, а не регулярний вираз. `-i` ігнорує регістр, `-n` додає номери рядків, `-v` показує рядки без шаблону. Код 0, якщо щось знайдено. |
| `sort` | `sort [-r] [файл]` | Відсортувати рядки. `-r` сортує у зворотному порядку. |
| `uniq` | `uniq [файл]` | Прибрати повтори рядків, що йдуть поспіль. |
| `wc` | `wc [-lwc] [файл]` | Порахувати рядки (`-l`), слова (`-w`) і байти (`-c`). Без прапорців показує все разом. |
| `head` | `head [-n N] [файл]` | Показати перші N рядків. За замовчуванням 10. |
| `tail` | `tail [-n N] [файл]` | Показати останні N рядків. За замовчуванням 10. |
| `tee` | `tee [-a] файл` | Записати ввід у файл і одночасно вивести його. `-a` дописує до файлу. |
| `seq` | `seq [початок] кінець` | Вивести числа від початку до кінця, не більше 1000 рядків. Якщо дано одне число, початок дорівнює 1. |

## 5. Оболонка, змінні і скрипти

| Команда | Синтаксис | Опис |
|---|---|---|
| `export` | `export [NAME=значення...]` | Задати змінні середовища. Без аргументів показує всі. |
| `unset` | `unset NAME...` | Видалити змінні. |
| `env` | `env` | Показати всі змінні середовища. |
| `printenv` | `printenv` | Синонім `env`. |
| `which` | `which команда...` | Показати шлях команди (умовний, `/bin/назва`). Код 1, якщо команди немає. |
| `type` | `type команда...` | Сказати, що це за команда: вбудована чи невідома. |
| `sh` | `sh файл` | Виконати рядки файлу як команди. Порожні рядки і рядки з `#` пропускаються. Файл до 4 КБ, вкладеність до 4 рівнів. |
| `run` | `run файл.lua` | Відкрити скрипт `.lua` у вікні. |
| `true` | `true` | Нічого не робить, код виходу 0. |
| `false` | `false` | Нічого не робить, код виходу 1. |

|---|---|---|
| `uname` | `uname [-a]` | Назва системи. З `-a` додає версію, чип і архітектуру. |
| `hostname` | `hostname` | Ім'я пристрою (`cardputer`). |
| `uptime` | `uptime` | Час від запуску. |
| `date` | `date` | Поточна дата і час. Потрібен час із мережі, тож спершу виконайте `wifi connect`. |
| `free` | `free` | Вільна і загальна пам'ять (heap). |
| `sleep` | `sleep секунди` | Пауза до 30 с. Блокує інтерфейс на цей час. |
| `reboot` | `reboot` | Перезапустити пристрій. Тільки root. |
| `poweroff` | `poweroff` | Перевести пристрій у глибокий сон. Прокинутися можна кнопкою RESET. Тільки root. |

## 7. Мережа

### `wifi`

Синтаксис має чотири варіанти:

- `wifi scan` — показати знайдені мережі (до 15) з рівнем сигналу і типом захисту. Доступно всім.
- `wifi connect SSID [ПАРОЛЬ]` — підключитися. Чекає до 15 с. Після підключення синхронізує час через NTP. Тільки root. Імена з пробілами беріть у лапки: `wifi connect "Home Net" "pass 123"`.
- `wifi status` — поточна мережа та IP-адреса або `disconnected`. Доступно всім.
- `wifi disconnect` — відключитися від мережі. Тільки root.

### `ip`

- `ip addr` (або `ip a`) — адреси інтерфейсів `lo` і `wlan0`.

### `curl`

- `curl URL` — HTTP або HTTPS GET. Виводить тіло відповіді: перші 2000 символів, HTML без розбору. Потрібен Wi-Fi.

### `browse`

- `browse [URL]` — відкрити вікно браузера, за потреби одразу з адресою.

### `tg`

Клієнт Telegram Bot API. Потрібен бот, створений через @BotFather, і Wi-Fi.

- `tg token BOT_TOKEN` — зберегти токен у `/root/telegram.conf` і почати опитування. Тільки root.
- `tg chat CHAT_ID` — задати чат за замовчуванням. Тільки root. Зазвичай він визначається сам: перший чат, який написав боту, стає типовим.
- `tg send TEXT` — надіслати текст у чат за замовчуванням.
- `tg to CHAT_ID TEXT` — надіслати текст в обраний чат.
- `tg inbox` — останні 10 повідомлень. Скидає лічильник непрочитаних.
- `tg poll` — перевірити нові повідомлення зараз.
- `tg status` — стан, чат за замовчуванням і кількість повідомлень.
- `tg open` — відкрити вікно Telegram.

Бот не може написати користувачу першим: спершу напишіть боту з Telegram. Вхідні повідомлення з кирилицею на екрані показуються як `?`. Відправлені з пристрою текст передається повністю.

## 8. Клавіші

### Термінал

| Клавіша | Дія |
|---|---|
| Enter | виконати команду |
| Del | стерти символ |
| Tab | доповнити назву команди (на початку рядка) або назву файлу. Якщо варіантів кілька, вони показуються списком |
| Fn + `;` / Fn + `.` | попередня / наступна команда з історії |
| Fn + `,` / Fn + `/` | прокрутка виводу вгору / вниз |
| Ctrl + C | скасувати рядок або введення пароля |
| Ctrl + U | стерти весь рядок |
| Ctrl + L | очистити вивід |

Під час введення пароля замість символів показуються зірочки. Tab та історія в цей час не працюють.

### Системні гарячі клавіші

| Клавіша | Дія |
|---|---|
| Opt | показати або сховати робочий стіл |
| Alt + Tab | перемкнути вікно |
| Ctrl + W | закрити активне вікно |
| Ctrl + Alt + T | відкрити термінал |
| Ctrl + R | на робочому столі перечитати `/apps` |
| W A S D або Fn + `; . , /` | рух по столу і списках |
| Enter | відкрити ярлик або виконати дію |
| Del | назад / стерти символ |

### Браузер

| Клавіша | Дія |
|---|---|
| G | редагувати адресу |
| Enter | в адресі: завантажити сторінку; у перегляді: відкрити вибране посилання |
| W / S | вибрати попереднє / наступне посилання |
| A / D | сторінка вгору / вниз |
| Del | назад за історією |

### Файловий менеджер

| Клавіша | Дія |
|---|---|
| W / S | вибрати файл або каталог; у перегляді файлу прокручує текст |
| Enter | відкрити каталог або переглянути файл |
| Del або A | на рівень вгору; з перегляду повертає до списку |

### Вікна входу і скриптів

- **Вхід:** Tab перемикає поля (логін і пароль), Enter переходить далі або входить.
- **Скрипт:** W/S прокручують вивід. Якщо скрипт чекає `wait_key()`, будь-яка клавіша його продовжує. Enter або Del закривають завершений скрипт.

## 9. Скрипти `.lua`

Файли з розширенням `.lua` у папці `/apps` з'являються на робочому столі, якщо перший рядок має вигляд `-- @name Назва`. Після додавання файлу натисніть Ctrl+R на столі.

Це власний мінімальний синтаксис, а не справжній Lua. Підтримуються такі виклики:

| Функція | Опис |
|---|---|
| `print(a, b, ...)` | Вивести значення через пробіл. Аргументи: рядки в лапках, числа, `battery()`, `uptime()`, `wifi()`, `time()`. |
| `sleep(мс)` | Пауза в мілісекундах. Інтерфейс не блокується. |
| `wait_key()` | Чекати, поки користувач натисне будь-яку клавішу. |
| `clear()` | Очистити вивід скрипта. |
| `cmd("команда")` | Виконати команду оболонки і вивести її результат. |
| `-- коментар` | Рядок-коментар. |

Приклад (`sd/apps/hello.lua`):

```lua
-- @name Hello
print("Hello from the SD card!")
print("Battery:", battery())
print("Wi-Fi:", wifi())
sleep(1000)
cmd("ls /")
wait_key()
print("Bye")
```

## 10. Приклади

```sh
# Список скриптів записати у файл і переглянути
ls /apps | grep .lua > /lists.txt
cat /lists.txt

# Числа від 1 до 5 у зворотному порядку (від 5 до 1)
seq 1 5 | sort -r

# Пошук .lua-файлів у /apps
find /apps -name "*.lua"

# Підключитися до Wi-Fi і синхронізувати час
wifi connect "HomeNet" "secret" && date

# Створити папку та файл у домашній директорії
mkdir -p ~/notes
echo "buy milk" > ~/notes/todo.txt
cat ~/notes/todo.txt

# Перевірити код виходу
cat /nofile; echo $?

# Виконати запасну дію, якщо команда не спрацювала
rm /nofile || echo "nothing to remove"

# Від імені звичайного користувача створити нового (sudo запитає пароль)
sudo useradd bob

# Від root створити користувача і змінити свій пароль
useradd alice
passwd
```
