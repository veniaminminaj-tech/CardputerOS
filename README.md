# KolibriX

Прототип KolibriX — мінімальної операційної системи для ESP32-S3 у стилі Linux для **M5Stack Cardputer ADV** (ESP32-S3) із зовнішнім дисплеєм ILI9341 320×240 на роз'ємі EXT.

> **Статус:** прототип. Код писався без компіляції на реальному пристрої. Якщо збірка видасть помилки, див. розділ «Обмеження».

## Можливості

- **Робочий стіл** із сіткою ярликів 6×4, рядком стану (час, Wi-Fi, батарея, користувач) і менеджером вікон.
- **Вхід у систему**: користувачі `root` і звичайні, команди `su`, `sudo`, `passwd`, перевірка прав доступу.
- **Термінал** з bash-подібною оболонкою: 64 команди, конвеєри `|`, перенаправлення `>` і `>>`, списки `;` `&&` `||`, змінні, шаблони `*` і `?`, Tab, історія.
- **Файловий менеджер** SD-карти з переглядом текстових файлів.
- **Міні-браузер**: HTTP і HTTPS GET, редиректи, HTML (заголовки, абзаци, посилання), вбудований CSS (`color`, фон, `font-weight`, `text-decoration`, `text-transform`, селектори тегів/`.class`/`#id`) і обмежена підмножина JavaScript (`var`/`let`/`const`, конкатенація рядків, `document.write`, `document.writeln`, `document.title`). Це не повноцінний Chromium: DOM, події, таймери, зовнішні скрипти, модулі, gzip/Brotli та сучасні вебзастосунки не підтримуються.
- **Telegram** через Bot API: вікно чату на робочому столі та команда `tg` у терміналі.
- **Скрипти `.lua`** із папки `/apps` на SD-карті з'являються на робочому столі без перепрошивки.

Повний перелік команд і їхнього синтаксису: [COMMANDS.md](COMMANDS.md).

## Обладнання

- M5Stack Cardputer ADV: ESP32-S3, вбудована клавіатура QWERTY, слот microSD.
- Зовнішній дисплей ILI9341 320×240 по SPI, підключений до роз'єму EXT 2.54-14P.

Піни дисплея задаються в `include/config.h` у блоці `EXT_TFT_*`. **Перевірте їх за вашою схемою** перед прошивкою.

## Збірка

1. Відкрийте папку проєкту у VS Code з розширенням PlatformIO.
2. Перевірте піни в `include/config.h`.
3. Виконайте `PlatformIO: Upload`, потім `PlatformIO: Monitor` (115200 бод).

Бібліотеки з `platformio.ini`: `M5Cardputer` і `LovyanGFX`. Хеш SHA-256 бере mbedTLS, яка входить у ESP32 Arduino core, окремо встановлювати її не треба.

## Системний диск `/` на microSD

У цій версії microSD є основним диском системи: абсолютний шлях `/etc/passwd`, `/root`, `/home` та `/apps` відповідає каталогам у корені карти. Внутрішня flash ESP32 використовується для прошивки й OTA, а не як домашня файлова система. Не виймайте карту під час роботи. Наразі драйвер Arduino `SD` очікує сумісну FAT32-карту; exFAT ще не підтримується.

## Підготовка SD-карти

Скопіюйте вміст папки `sd/apps/` на корінь карти. Решту структури створить система:

```
/apps/hello.lua       скрипт, з'явиться на робочому столі
/etc/passwd           база користувачів, створюється при першому запуску
/root/                домашня папка root
/home/<ім'я>/         домашні папки звичайних користувачів
```

## Два застосунки і стартове меню

Пристрій не компілює код із SD. На карту копіюються **скомпільовані** прошивки.

**Збірка:**

1. Launcher один раз по USB: `pio run -e launcher -t upload`.
2. KolibriX: `pio run -e cardputer_os`. Файл: `.pio/build/cardputer_os/firmware.bin`.
3. Gaming збирайте у своєму проєкті з таким самим `partitions_cardputer.csv` і підключеним `include/boot_guard.h`. У його `setup()` першим рядком має бути `bootReturnToLauncher();`. Розмір застосунку має бути не більше 2.6 МБ.

**SD-карта:**

```
/boot/cardputer_os.bin     KolibriX
/boot/gaming.bin           гра або емулятор
```

**Поведінка:**

- Після старту з'являється меню. Через 5 секунд без натискань запускається останній вибраний застосунок.
- Перший запуск застосунку прошиває його з SD в OTA-слот. Далі слот уже має образ, і запуск швидкий.
- Якщо ви оновили `.bin` на SD, виберіть пункт **Update both from SD**.
- Застосунок під час старту сам повертає завантаження на Launcher. Тому після наступного перезапуску знову відкривається меню.

Перед прошивкою перевірте розмір flash-пам'яті: таблиця розділів розрахована на 8 МБ.

## Перший запуск і вхід

Після завантаження з'являється вікно **Login**. Гарячі клавіші та робочий стіл стають доступними лише після входу.

Перший запуск створює користувача **`root` з паролем `root`**. Одразу змініть його:

1. Введіть `root`, натисніть Enter, потім пароль і Enter.
2. Відкрийте термінал (Ctrl+Alt+T) і введіть `passwd`.
3. Створіть звичайного користувача: `useradd ім'я`.

## Керування

### Робочий стіл і системні клавіші

| Клавіша | Дія |
|---|---|
| W A S D або Fn + `;` `.` `,` `/` | рух по столу і списках (Fn + `;` це ↑, `.` це ↓, `,` це ←, `/` це →) |
| Enter | відкрити ярлик або виконати дію |
| Del | назад / стерти символ |
| Opt | показати або сховати робочий стіл |
| Alt + Tab | перемкнути вікно |
| Ctrl + W | закрити активне вікно |
| Ctrl + Alt + T | відкрити термінал |
| Ctrl + R | на робочому столі перечитати `/apps` |

### Термінал

- Tab доповнює назви команд і файлів.
- Fn + `;` і Fn + `.` гортають історію команд.
- Fn + `,` і Fn + `/` прокручують вивід.
- Ctrl+L очищає вивід, Ctrl+U стирає рядок, Ctrl+C скасовує введення.
- Команди `su`, `sudo`, `passwd` і `useradd` питають пароль прямо в терміналі, замість символів показуються зірочки.

Детально: [COMMANDS.md](COMMANDS.md), розділи «Клавіші» та «Оболонка».

### Браузер, файли і скрипти

- **Браузер:** G — редагувати адресу, W/S — вибрати посилання, Enter — перейти, A/D — сторінка вгору або вниз, Del — назад.
- **Файли:** W/S — вибір, Enter — відкрити, Del або A — на рівень вгору.
- **Скрипти:** W/S — прокрутка, Enter або Del — закрити завершений скрипт.

## Обмеження

- **Лише ASCII в інтерфейсі.** Вбудований шрифт LovyanGFX не містить кирилиці, тому українські та російські літери виводяться як `?`. Щоб вивести текст українською, потрібен растровий шрифт із кирилицею. Тому повідомлення в інтерфейсі англійською.
- **Права доступу програмні.** FAT не зберігає права, їх перевіряє прошивка. Паролі в `/etc/passwd` (SHA-256 із сіллю, 1000 раундів) захищають від випадкового доступу, але не від того, хто має вашу карту: її можна вийняти й перебрати паролі.
- **Скрипти `.lua` не є справжнім Lua.** Це підмножина власного синтаксису з функціями `print`, `sleep`, `wait_key`, `clear`, `cmd`.
- **HTTPS без перевірки сертифіката** (`setInsecure`). Для прототипу це прийнятно, для реального використання потрібен CA.
- **Блокування інтерфейсу.** Підключення до Wi-Fi, завантаження сторінок і `sleep` зупиняють інтерфейс на час операції.
- **Код не скомпільовано.** Найімовірніші місця для правок: API `M5Cardputer` і `LovyanGFX` (залежить від версій), `SD.totalBytes()` і `SD.usedBytes()` у `df`, виклики `mbedtls_sha256_*` у `users.cpp`. Якщо збірка видасть помилки, надішліть лог компілятора.
